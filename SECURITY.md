# Security Policy

This pilot is a static, client-side educational prototype and does not collect or transmit user data. It has no authentication, server, API credentials, or third-party scripts.

## Reporting an issue

Please open a GitHub issue with reproduction steps. Do not include passwords, tokens, personal student records, or private organisation data in public issues.

## Future changes

If persistence is moved to a server or user accounts are introduced, the project must add an explicit privacy policy, access control, secure session handling, data retention rules, and a security review before collecting real student information.
