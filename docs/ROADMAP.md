# Roadmap

## Pilot 0.4 — current

- Modern responsive Persian RTL interface
- Clickable simplified As-Is BPMN case view
- Parameter controls and intervention toolkit
- Local deterministic-seed simulation
- Baseline / scenario KPI comparison
- To-Be preview for affected nodes
- Ten-item fixed-form assessment across five difficulty levels
- Weighted competency diagnostics and Decision Replay
- Local scenario history and JSON report export
- Product and teaching documentation

## 0.5 — improve instructional reliability

- Instructor review of assessment text and scoring
- More explicit metric definitions and target bands
- Scenario comparison across saved runs
- Accessibility audit and keyboard-only interaction testing
- Print-ready instructor/student reports
- Export experiment and assessment records to CSV
- Improved process model legend and BPMN notation explanation

## 0.6 — broaden process reasoning

- Additional case studies (loan approval, patient intake, procurement)
- More intervention types with explicit preconditions and side effects
- Process fragment editing with constrained building blocks
- BPMN sequence-flow validation for supported patterns
- More item formats: ranking, multi-select, and structured rationale rubrics

## 0.7 — stronger analytics

- Work-in-process tracking
- Time-dependent arrivals and staffing calendars
- Multiple simulation replications and confidence intervals
- Sensitivity analysis for demand, service time, and rework rates
- Pareto comparison for cost, cycle time, and quality objectives

## 1.0 — multi-case teaching platform

- Instructor authoring interface for cases and assessment sets
- Student cohorts and assignment management (requires a backend and privacy design)
- Versioned projects and rubric-based review
- Optional collaboration with explicit access control
- Portable BPMN 2.0 XML import/export and validation for a defined supported subset

The roadmap is directional. Items beyond the current static prototype may require architecture changes, user research, and additional testing.
